# CredVisible — Credit Score for the Invisible

CredVisible is an alternative, privacy-preserving credit scoring and safe loan limit prediction engine for gig and informal economy workers.

## 🚀 Features
- **Page 1: Onboarding & Account Linking:** Simulated OAuth/Platform login integration.
- **Page 2: First-Time Credit Scoring (Stage 1):** Uses bank/UPI consent data and OCR bill proof uploads to evaluate daily earnings, volatility, platform ratings, and utility punctuality.
- **Page 3: Post-Repayment Upgrade (Stage 2):** Connects to NBFC repayment records to recalculate and upgrade loan limits for repeat borrowers.
- **Explainable AI Outputs:** Generates transparent reason codes for lender compliance.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Python (Flask, Flask-CORS)
- **Machine Learning:** Scikit-Learn (Random Forest Regressors), Pandas, NumPy, Joblib
